# 증권사 수수료, 어디가 제일 쌀까?

> 키움·한투·미래에셋·NH·삼성·KB 6개 증권사의 국내주식 매매수수료를 한눈에 비교하는 대시보드. 인터넷에서 최신 비교글을 찾아 헤매던 불편에서 출발했다.

**라이브 데모: [broker-fee-dashboard.vercel.app](https://broker-fee-dashboard.vercel.app)**

## 핵심 결론

- 100만원 거래(비대면 스마트폰 채널) 기준, 6개 증권사 매매수수료를 공공데이터포털 API로 실시간 조회한다.
- 값은 **금융위원회_금융투자회사공시정보(data.go.kr)** 공식 API에서만 가져온다. 지어내거나 캐시로 채운 값이 아니다.
- API가 응답하지 않으면 "값 없음"을 그대로 보여준다. 대체값을 임의로 채우지 않는다.
- 인증키는 서버 환경변수에서만 읽고, 화면(프론트엔드) 코드에는 절대 넣지 않는다.

| 증권사 | 수수료 | 기준일 |
|---|---|---|
| 키움증권 | 150원 | 2020.12.31 |
| 한국투자증권 | 141원 | 2021.11.25 |
| 미래에셋증권 | 100원 | 2025.03.04 |
| NH투자증권 | 2,472원 | 2020.06.10 |
| 삼성증권 | 2,972원 | 2021.10.01 |
| KB증권 | 1,200원 | 2021.11.25 |

## 1. 문제 정의

증권사별 국내주식 매수매도수수료를 비교하려면 매번 인터넷에서 가장 최근 비교글을 검색해 찾아 들어가야 했다. 정보가 오래됐거나 정확하지 않을 때도 많았다. 나와 공유 대상이 주기적으로, 정확한 최신 수수료를 한 화면에서 보고 싶었다.

## 2. 시장 조사

같은 문제를 푸는 서비스 5곳(증권사 공식 비교 페이지, 금융투자협회 통합공시, 네이버페이 증권, 커뮤니티 비교글, 유튜브 리뷰)을 비교한 결과, 최신성과 신뢰성을 동시에 만족하며 "내가 쓰는 증권사만" 모아 보여주는 곳은 없었다. (근거와 출처는 `market-research.md` 참고)

## 3. 데이터

| 항목 | 내용 |
|---|---|
| 출처 | 공공데이터포털 — 금융위원회_금융투자회사공시정보 |
| 오퍼레이션 | `getStockTradingFeeInfo` |
| 범위 | 국내주식 매매수수료만 제공 (미국주식·환전수수료는 이 API에 없음) |
| 기준 | 거래금액 100만원 구간, 비대면 스마트폰 채널 |
| 인증 | 서비스키를 서버 환경변수(`DATA_GO_KR_SERVICE_KEY`)로만 주입 |

## 4. 접근 방법과 정직성 원칙

1. 배포 전에 API를 실제로 호출해 응답 항목을 먼저 확인했다 (`resultCode`, `items.item[].cfe` 등).
2. 각 증권사마다 실시간으로 API를 호출하고, "변경후" 상태·스마트폰 채널 조건에 맞는 최신 행을 고른다.
3. 호출이 실패하거나 조건에 맞는 데이터가 없으면 값을 지어내지 않고 상태를 그대로 노출한다: `live`(실시간 성공) / `no_data`(조건에 맞는 데이터 없음) / `error`(호출 실패).
4. 인증키는 `.env`(로컬) 또는 Vercel 환경변수(배포)에서만 읽으며, 저장소와 화면 코드 어디에도 값이 노출되지 않는다.

## 5. 한계 및 다음 과제

- **환전수수료**: 이 공공 API에는 항목이 없어 아직 연결되지 않았다. 각 증권사 앱에서 값을 직접 확인해 수동으로 채워야 한다.
- **미국주식 수수료**: 이번 범위에서 제외했다. (국내주식 실데이터 우선 원칙)
- 데이터 갱신 주기는 증권사가 공시를 올리는 주기에 달려 있어, 일부 항목은 기준일이 오래됐을 수 있다.

## 6. 프로젝트 구조

```
index.html     화면 (프론트엔드, 인증키 없음)
server.js      로컬 개발용 서버 (Vercel 배포에는 안 쓰임)
api/fees.js    Vercel 서버리스 함수 — /api/fees
lib/fetchFees.js  공통 로직: data.go.kr 호출 및 대표값 선정
.env           로컬 전용 인증키 (저장소에는 포함 안 됨)
```

## 7. 실행 방법

**로컬:**
```
node server.js
```

**배포:** Vercel에 GitHub 저장소를 연결하고, 프로젝트 환경변수에 `DATA_GO_KR_SERVICE_KEY`를 등록하면 `api/fees.js`가 자동으로 서버리스 함수로 배포된다.
